# LK 通用修补工具（绿厂系 / 蓝厂系）

MTK Little Kernel 通用修补工具，按厂商分目录。

```
通用修补工具/
├── 绿厂系修补/
│   ├── 通用修补工具.cpp           源码(伪回锁+免授权深刷)
│   ├── 绿厂通用修补工具.exe     Windows
│   └── 绿厂通用修补工具_android Android
└── 蓝厂系修补/
    ├── 蓝厂通用修补工具.cpp       源码(免重签+语义打桩, 保函数结构)
    ├── 蓝厂通用修补工具.exe       Windows
    ├── 蓝厂通用修补工具_android   Android
    └── 蓝厂LK修补_方案说明.md     方案说明
```

共同点：
- AArch64 指令语义自动定位，不写死偏移，适配多套构建；
- 对每个被改动分区的 cert2 做免重签（90B 前置块重算内容/头哈希），不动原厂证书体/cert1；
- 打桩尽量单指令原位、保留原函数结构。

用法：拖拽 lk 镜像到对应 exe / 命令行，选择类别（1 伪装回锁 / 2 去黄字 / 3 去写保护 / 回车=全部）。
